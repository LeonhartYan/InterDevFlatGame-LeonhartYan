# InterDevFlatGame
This game was inspired by my own process of thinking for game inspiration: wandering on the subway station platform, head bowed in thought, dodging the noisy crowd, staring blankly at the garbages on the ground. It suddenly occurred to me that I could use this very process of searching for inspiration as inspiration itself to create a game. I hope the possible audiences may have shared memories and sympathy when they experience it.  I finally landed on a concept that “finding inspiration is like a treasure hunt in garbage. While making this game, I gained an understanding of the transition between Gamemaker and Unity's code structures, animation creation, sound play, rigid body, colliders, and basic 2D character movement. I believe my concept holds merit, and the game largely achieved its intended purpose. I also combined the photograph and my hand-drawn sprites to make a realistic but funny scene. I now aim to delve deeper into Unity's camera management.
